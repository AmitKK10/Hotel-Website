# 🌊 Digha Beach Resort

### Luxury Hospitality Website • Premium UI/UX • Next.js • PWA

A premium, modern and immersive hotel/resort website designed for **Digha Beach Resort**, focused on luxury presentation, smooth animations, responsive design, local tourism discovery and direct WhatsApp-based booking.

The project is built as a production-ready hospitality website and can also be adapted as a reusable/white-label solution for hotels, resorts and other hospitality businesses.

## 📌 Project Overview

Digha Beach Resort is a modern hospitality website concept designed to provide visitors with an engaging digital experience before their stay.

The website combines premium visual design with practical hotel features including room discovery, amenities, gallery exploration, dining information, special offers, nearby attractions, itinerary planning and direct booking through WhatsApp.

The interface is designed with a luxury-inspired visual system using deep dark tones, elegant typography, glassmorphism, subtle gold accents, smooth transitions and immersive imagery.

## 🌴 Guest Experience

The website is designed around the complete guest journey:

**Discover → Explore → Compare → Plan → Book**

Visitors can explore the resort, understand the available rooms and amenities, discover nearby attractions, check dining options and contact the resort directly through WhatsApp.

## 📱 Progressive Web App

The website is designed as a PWA so visitors can install it on supported devices and access the resort experience from their home screen.

PWA features include:

- Web App Manifest
- Standalone application mode
- Install prompt
- Mobile installation support
- iOS installation guidance
- Custom application icons
- Responsive mobile-first experience

## 💬 WhatsApp Booking

The booking experience is designed around direct communication with the resort.

Visitors can select a room or booking option, enter their requirements and continue the conversation through WhatsApp.

This avoids unnecessary complexity for a small or independent hospitality business while still providing a convenient booking workflow.
